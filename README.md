## 🚀 배포 방법 (Deployment)

단일 정적 HTML 파일 구조이므로 배포가 매우 간단합니다.

### Cloudflare Pages 배포 방법
1. **Cloudflare 대시보드** 로그인 (`dash.cloudflare.com`).
2. **Workers & Pages** ➡️ **Create application** ➡️ **Pages** 선택.
3. **Upload assets**를 선택한 후, 프로젝트 명을 입력합니다.
4. 루트 폴더의 `index.html` 파일(또는 폴더 전체)을 웹브라우저 창에 드래그 앤 드롭하여 업로드합니다.
5. **Deploy site**를 누르면 몇 초 안에 나만의 도메인으로 전 세계에 무료 배포됩니다.
